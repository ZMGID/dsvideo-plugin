# 电商 H3 出片（骨架）

本技能是 **dsvideo-plugin** 的流水线入口。面向 Codex、Claude Code 及同类编码代理，不是 MiniMax Hub，也不是桌面 App。

必须按下列顺序执行，不要跳步，不要发明 Hub / Comfy Cloud / 第三方出片产品。

## 1. 收集素材与规格

向用户确认（缺什么就问，已给的不要重复盘问）：

- **产品图**：至少一张；多图时问清主图 / 细节图 / 场景图。有图时后面优先走 I2VA。
- **卖点**：核心利益点、使用场景、口播/字幕要点（若有）。
- **投放平台 + 规格**：时长、画幅（如 9:16 / 1:1 / 16:9）。没给则先按常见竖屏短视频（约 9:16、时长落在 H3 允许区间）推进，并在回复里写明假设。
- **本地工作流**：使用用户已经配置好的工作流；无法确定是哪一个时，只问一次名称或路径。

**平台合规：** 若尚未写入本仓库的平台细则，不要编造抖音 / 淘宝 / 得物等细则。先用通用电商卫生规则继续出片，并明确告知「平台规则尚未补全」：

- 不写虚假折扣、虚构销量、医疗功效或违禁承诺。
- 画面文字可读，信息不过载。
- **产品是主角**：镜头、用光、构图都围着商品，不要喧宾夺主。

## 2. 改写成 MiniMax-H3 提示词

严格遵循同级技能 **`h3-prompt-writing`**（本插件 `skills/h3-prompt-writing/`）的结构与字段名：

- 有产品图 → **优先 I2VA**（首帧出发）。
- 仅有文案 → T2VA。
- 用户给了首尾帧 → FL2VA；只给尾帧 → L2VA；完整参考素材 → Ref2VA。

改写时读该技能的 `references/base-en.txt` 或 `references/ref-en.txt`，保留其字段顺序、标签与时码记法。把卖点写进画面动作、口播/字幕与音景，而不是另起一套自由格式。

## 3. 出片（主路：局域网 ComfyUI + comfy-mcp）

**主路必须是本机 MCP 客户端通过 `comfy-mcp`（stdio）打到机柜 GPU 上的 ComfyUI。禁止 Comfy Cloud、禁止 `comfy-cloud` 插件/技能、禁止 npm `comfyui-mcp`。**

已有本地工作流时读取 [references/comfy-workflow-safety.md](references/comfy-workflow-safety.md)。

前提（由用户保证，本技能不安装、不探测密钥）：

- GPU 箱已用 `--listen 0.0.0.0 --port 8188` 拉起 ComfyUI。
- 插件已将 `COMFYUI_URL` 配置为公司局域网 ComfyUI：`http://192.168.1.171:8188`。
- `COMFYUI_URL` 只影响提交 / 排队 / 上传 / 取片；生命周期（启停）与模型下载仍发生在 MCP 所在机器。H3 权重必须已经在 3090 箱上。

操作：

1. 用 comfy-mcp 探活该 `COMFYUI_URL`。
2. 运行用户已经配置好的工作流，只在一次性副本中改提示词、输入图片/视频、视频比例和时长；其他参数一律不改，也不覆盖原文件。
3. 提交前运行差异检查，通过后再排队并记录 `prompt_id`。
4. 找不到工作流时只问用户名称或路径；不要自行搜索替代模板。
5. 本地失败时只简要报告真实错误；不要推测模型兼容性、替换模型或自动转付费 API。

回复只保留结果、真实错误和必须由用户决定的事项。不要主动展开硬件、模型文件、模板兼容性或费用说明。

## 4. 备选（仅失败时）：MiniMax 按量 API

仅当用户明确选择改走付费 API 时，使用同级技能 **`minimax-h3-api`**（本插件 `skills/minimax-h3-api/`）。本地失败本身不授权自动切换。

- 这是 MiniMax **按量 / Pay-as-you-go API**，不是 MiniMax Hub。
- 付费提交前必须让用户明确选择 `768P` 或 `2K`；未给分辨率就询问，禁止默认成 `2K`、静默升级或降级。
- 先 dry-run 核对模型、真实分辨率、时长、画幅和模式，再执行一次付费提交；成功后还要核对任务返回的分辨率与时长。
- 按该技能自己的规则，通过插件内置脚本直接调用 MiniMax 官方 V2 API，提交、等待并下载。不要安装 `mmx-cli`。
- 不要回落到 Hub、comfy-cloud，或任何「一键广告生成器」类技能。

## 5. 交片

把成片的 **本地路径或 URL** 交给用户，并简要说明：

- 走的是主路 Comfy 还是 API 备选；
- 使用的模式（I2VA 等）与假设的时长/画幅；
- 若平台规则未补，提醒这是通用电商卫生，不是平台审核清单。
