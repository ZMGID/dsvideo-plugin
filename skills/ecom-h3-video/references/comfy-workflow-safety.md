# ComfyUI 本地工作流规则

- 用 `scripts/fetch_saved_workflow.py` 读取服务器上的指定工作流，不扫描本机或工作区中的其他工作流，不覆盖服务器原文件。
- 只允许在一次性副本中修改提示词、输入图片/视频、视频比例和时长；单图分支可将旧任务类型规范为服务器标准枚举 `Ref2VA`，其他参数一律不改。
- 用 `scripts/comfy_workflow_guard.py` 检查原工作流和副本，只放行上述字段的准确 JSON Pointer；出现其他差异就不提交。
- 不用 `comfy-mcp validate_workflow` 检查员工电脑上的模型；它不是局域网服务器的模型清单。只做差异检查，然后向局域网服务器提交。
- 找不到指定工作流或提交失败时只报告真实错误，不询问其他路径、不推测兼容性、不换模型、不自动转付费 API。
